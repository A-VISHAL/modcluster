# ModPulse Frontend Architecture - Before & After

## 🔴 BEFORE: Conflicting Custom Posts (Broken)

```
User clicks menu "Create ModPulse Post"
           ↓
reddit.submitCustomPost({ entry: 'default' })
           ↓
    Devvit runtime loads...
           ↓
      ┌────────────────┬────────────────┐
      │ BLOCKS PATH    │ WEB PATH       │
      │ (ACTIVE) ❌    │ (IGNORED)      │
      └────────────────┴────────────────┘
           ↓
  Devvit.addCustomPostType()
  renders "ModPulse Working" ❌
           ↓
  Browser displays:
  ┌─────────────────────────┐
  │  ModPulse Working       │  ← Plain text only
  │  (No dashboard!)        │     No styles
  │                         │     No interactivity

- devvit.ts had Devvit.addCustomPostType({name: 'ModPulse'...})
- This Blocks registration took precedence
- devvit.json Web config was ignored
- Both couldn't coexist
```

## 🌐 Runtime Flow

### When a New ModPulse Post is Created

```
Step 1: User Action
─────────────────────────
User clicks: "Create ModPulse Post" menu item
         ↓
  Menu endpoint called: /internal/menu/modpulse-create
         ↓


Step 2: Backend Creates Post
─────────────────────────────
reddit.submitCustomPost({
  title: "ModPulse (2026-05-07...)",
  entry: "default"  ← References devvit.json entrypoint
})
         ↓
  Post created with ID: t3_abc123xyz


Step 3: User Clicks Post
─────────────────────────
New post appears in feed
         ↓
  User clicks on ModPulse post
         ↓
  Browser navigates to post


Step 4: Devvit Loads Web Custom Post
────────────────────────────────────
Devvit looks up: entry: "default"
         ↓
  Finds in devvit.json:
  "entrypoints": {
    "default": {
      "entry": "modpulse.html",  ← This file
      "height": "tall"
    }
  }
         ↓
  Loads: dist/client/modpulse.html
         ↓


Step 5: Browser Renders HTML
─────────────────────────────
Browser receives HTML:
   <script>console.log('[ModPulse Web] NEW DASHBOARD...')</script>
   <script type="module" src="/default.js"></script>
   <link rel="stylesheet" href="/default.css">
   <body><div class="app">...</div></body>
         ↓
  Console shows:
  "[ModPulse Web] NEW DASHBOARD BUILD ACTIVE - Frontend entrypoint loaded at: ..."


Step 6: JavaScript Module Loads
────────────────────────────────
default.js executes:
   console.log("[ModPulse Web] NEW DASHBOARD BUILD ACTIVE - JavaScript runtime initializing")
   
   // Initialize DOM elements
   const app = document.querySelector('.app')
   
   // Fetch dashboard data
   const data = await fetch('/api/dashboard')
   
   // Render all components
   renderStatus(data)
   renderMeta(data)
   renderHeroMetrics(data)
   renderHandover(data)
   renderJury(data)
   
   // Set up event listeners
   // Set up auto-refresh timer (15s)
         ↓


Step 7: Dashboard Displays
──────────────────────────
Browser shows:
   ✅ Header with ModPulse branding
   ✅ Status chips (Redis, Moderation, Jury)
   ✅ Operations Console hero section
   ✅ Metrics (Queue, Reports, Toxicity, Burnout)
   ✅ Handover card (with current status)
   ✅ Jury board (with pending cases)
   ✅ Community health stats
   ✅ Fully styled with CSS
   ✅ All buttons interactive
         ↓


Step 8: Auto-Refresh Loop
──────────────────────────
Every 15 seconds:
   fetch('/api/dashboard')
   ↓ 
   Update all components with new data
   ↓
   Dashboard stays current
```

## 🐛 What Was Wrong Before

```
The Conflict:
────────────────

devvit.ts (Line 31-43):
  Devvit.addCustomPostType({
    name: 'ModPulse',
    render: () => {
      return Devvit.createElement('vstack', undefined,
        Devvit.createElement('text', undefined, 'ModPulse Working')
      )
    }
  })

PLUS

devvit.json:
  "post": {
    "dir": "dist/client",
    "entrypoints": {
      "default": {
        "entry": "modpulse.html"  ← Full dashboard
      }
    }
  }

EQUALS: 

❌ Blocks version wins
❌ Web version ignored
❌ Only "ModPulse Working" renders
❌ No dashboard shown
```
